# Integrations

Commerce platform plugins built on Autlantic Billing (hosted API + language SDKs).

| Integration | Path | Notes |
|-------------|------|--------|
| WooCommerce | [`woocommerce/`](./woocommerce) | Full payment gateway. Soft WooCommerce Subscriptions support. Uses `autlantic/billing` PHP SDK. |

Language clients live under [`sdks/`](../sdks). Do not put Autlantic platform merchant secrets or URLs here.
